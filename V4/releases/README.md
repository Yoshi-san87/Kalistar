# Livraisons

Pour une nouvelle publication : `YYYY-MM-DD-vX.Y.Z/`.
Conserver le README du perimetre, les commandes executees et les preuves
selectionnees. Indiquer les echecs/limites ; ne pas appeler une preparation
locale une publication en ligne.

Les historiques gardent leurs noms existants. Un ancien compte de cartes
ou resultat de test decrit uniquement son lot/commit.
Ne pas committer le build `V4/deploy/dist/` ni toutes les captures intermediaires.
