# Scripts de production

`stable/` contient les outils de la route native actuelle, interpretes avec les
registres `../template-stable/` et les consignes V4.
Les glyphes blancs actuels passent notamment par
`stable/white-weapon-component.cjs`.

Les scripts de preparation et anciens essais `master/`, `momo-bottom/` ou dates
restent des sources historiques. Ne pas les relancer automatiquement pour
produire une carte actuelle.

Un nouveau script reutilisable va dans le domaine approprie ; une experimentation
va dans `work/scratch/`. Documenter les entrees/sorties et les prerequis.
Ne pas introduire de nettoyage implicite ou de paths absolus propres au poste.
