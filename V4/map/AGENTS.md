# Maps Kalistar

- Read `DIRECTION_ARTISTIQUE.md` and open its relevant visual references before
  generating or revising a map.
- Use `versions.json` to identify current geography. Map 1.0 remains the
  reference for crisp ink and parchment; use domain references for landmarks
  and biomes without restoring their obsolete geography.
- Preserve previous versioned images. Add a new version, exact prompts,
  supplied location references and SHA-256 provenance.
- Inspect the complete image, edited terrain and city silhouettes for drift,
  poor seams, old terrain ghosts, distorted buildings or misspelled labels.
- A map proposal does not itself replace the site's runtime background.
