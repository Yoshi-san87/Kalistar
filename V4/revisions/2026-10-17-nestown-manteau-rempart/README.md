- Verification pixel hors illustration : zero difference sur les quatre cartes.
- Reouverture PSD : zero difference ; codes-barres verifies.
- Installation transactionnelle dans les memes creations, sans nouvel identifiant.

before.json conserve les empreintes avant revision. verification.json,
verified.json et transaction.json documentent les sorties et leur installation.

Les anciens rapports et verrous de reference ne sont pas modifies.

Commandes locales : node revise.cjs prepare / render / verify / publish.
