# Revisions

Un lot date documente un changement cible : demande, perimetre,
originaux preserves, nouvelles sources, controles et statut de publication.
Une revision peut contenir une ressource encore active ; ce dossier n'est pas
un bac a supprimer.

Les anciens rapports et hashes restent immuables. Ne pas refaire un verrou
pour rendre une verification verte. Les tentatives intermediaires suivantes
vont dans `work/`, pas automatiquement dans un nouveau rapport suivi.
