# L'Homme Mystere

User-requested display rename of model 49901503, formerly LE SPHINX, to
L'HOMME MYSTÈRE. The characterId sphinx-batman remains unchanged so existing
compositions, ownership, equipment restrictions and saved matches keep working.

Only the editable NOM layer was changed in a duplicate of the current PSD.
The illustration, frame, faction banner, crystal, stats, skills, positions and
all other native layers remain unchanged. Original sources and original
verification reports are preserved in originals/.

The native proof records zero pixels changed outside the name area, an identical
reopened PSD render and a readable unchanged barcode. The revision chains after
2026-10-09-crossover-crystals through nativeRevision.previous.

The live equipment lore and the Batman proposal gallery use the new name.
Historical production sets and reports retain the former name.

Commands: node revise.cjs prepare, render, verify, publish (one-time production);
node --test integration.test.cjs (repeatable active catalogue checks).
