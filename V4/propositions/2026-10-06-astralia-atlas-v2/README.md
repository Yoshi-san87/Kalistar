# Astralia - simplified atlas V2

Author-requested revision of the V1 Collection background on 6 October 2026.

## Geography

- One large continent on either side of the map.
- One isolated island in the middle.
- A southern archipelago.
- One frozen northern continent physically joining the side continents.
- A clear world overview rather than Earth-shaped fragmented continents.

This ambience illustration follows the author's broad arrangement, without
introducing place names, factions or a canonical political geography.
Story and character reading surfaces are unchanged.

## Provenance

Generated with the built-in image_gen tool. The author explicitly selected the
first geography revision via an attached image, rather than the subsequent
more minimal study. The selected source is
`astralia-planisphere-selected-v2.png`, with the exact `prompt-geography.txt`.
Its decoded pixels match the author's attachment exactly. The optional
`astralia-planisphere-minimal-study-v2.png` and its simplification prompt remain
preserved but are not used by the site.
No approved card image or frame was modified.

The selected original and runtime WebP remain unblurred. Only the Collection
background pseudo-element has a static 1.6px CSS blur; cards, captions, controls,
Story and character notebooks are not blurred. The 4px bleed prevents filter
edges showing through. No duplicate blurred bitmap is generated.

The runtime WebP is a format conversion only. Run `node prepare.cjs` to rebuild
it with the bundled Sharp runtime; `manifest.json` records source and runtime
dimensions, bytes and SHA-256. The source remains outside the Pages artifact.
