# Jelly-Joe - Cinq propositions de pirate dandy

Illustrations alternatives uniquement. Aucune n'a remplace la carte, le PSD ou le template valides. Aucun chiffre, cadre, badge ou mecanisme n'a change.

1. `01-charmeur-insolent.png` : regard en coin, moustache fine, posture nonchalante.
2. `02-marquis-naufrage.png` : silhouette aristocratique, pose assise, sourire retenu.
3. `03-flambeur.png` : plus solaire et expansif, chope et lance en main.
4. `04-poete-des-quais.png` : sourire complice, tete appuyee sur la main, pose relachee.
5. `05-cabotin.png` : toast theatral, tentacules violets, couvre-chef plus asymetrique.

Les cinq PNG sont des copies integrales des sorties de l'outil image_gen integre. Chaque proposition garde la chope en verre, la lance, le manteau noir, la chemise claire, l'echarpe bordeaux et les accessoires du costume. References : illustration Jelly-Joe V4-02 pour le costume ; Momo et Valazar pour la peinture narrative Kalistar.

`comparatif-visages.png` rapproche les visages ; `comparatif-illustrations.png` montre les compositions completes. Les recadrages concernent uniquement les comparatifs, jamais les originaux.

Prompts exacts : `prompt-01.txt` a `prompt-05.txt`. Provenance, dimensions et empreintes : `manifest.json`. `prepare-comparisons.cjs` assemble les planches et verifie que les cartes et le template n'ont pas change.

Le choix utilisateur precedera l'integration dans l'objet dynamique du PSD. Le cadrage final dans la fenetre de carte sera alors verifie avec le cadre existant.
