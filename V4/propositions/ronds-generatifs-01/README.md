# Kalistar V4 - essai de ronds generatifs

Deux propositions de direction artistique, non integrees au PSD valide.

- `01_ROND_ATK_PHYSIQUE_OR.png` : rond physique, or facette, fines bordures cuivre, centre dore sans symbole.
- `02_ROND_ATK_MAGIQUE_ELECTRO.png` : declinaison electrique, circuit lumineux sur le pourtour.

Les deux PNG font 1254 x 1254 pixels et possedent un veritable canal alpha. Verification : transparence presente et aucun pixel de bord d'opacite superieure a 32/255. La version magique garde un halo volontairement expressif ; son intensite reste a valider dans la carte.

Les chiffres et pictogrammes ne sont pas integres aux images : ils resteront des calques dynamiques. Aucun changement dans le PSD Momo, les cartes existantes, le site ou les donnees.

Ces images generatives sont des propositions visuelles, pas encore des composants calibres pixel par pixel pour le gabarit. Le cadrage et les dimensions du cercle seront a harmoniser lors de l'integration apres validation.

Outil utilise : image_gen integre. Prompts complets dans `PROMPTS.md`.
