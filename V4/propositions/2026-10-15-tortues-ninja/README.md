# Tortues Ninja : propositions d'illustrations

Lot du 15 octobre 2026, dix illustrations selectionnees pour la production native.
April et Michelangelo ont une nouvelle scene ; Shredder est entierement regenere
dans le dojo apres les deux corrections locales de griffes non retenues.
Les cartes sont produites dans le [lot natif](../../expansions/2026-10-15-tortues-ninja/README.md).

## Consultation

Ouvrir `index.html` directement. Les vignettes WebP sont des derives de lecture ;
les dix PNG originaux sont conserves sans retouche dans `images/`.

Personnages : Leonardo, Raphael, Donatello, Michelangelo, Shredder, Krang,
Bebop, Rocksteady, April O'Neil et Maitre Splinter.

## Direction

Peinture narrative Kalistar, matieres peintes, silhouettes lisibles et eclairage
motive. Poses et lieux distincts : toit pluvieux, tunnel, atelier, passerelle,
cour industrielle, installation dimensionnelle, garage, quai, toit et dojo.
Les decors soutiennent le personnage sans accumuler les details.

References visuelles inspectees : Momo et Valazar dans les illustrations V3.
Aucune reference n'a ete modifiee. Aucun cadre de carte n'a ete genere.

## Provenance

Generation avec le **generateur integre image_gen**, un appel par illustration.
Pas de CLI/API de secours. Les prompts exacts, chemins source du generateur,
dimensions et SHA-256 des copies sont dans `selection.json`. Les retouches et
regenerations sont documentees dans `revision-02.json` ; les variantes precedentes
restent preservees. Le statut de production suit la demande de cartes et ne
pretend pas constituer une nouvelle approbation artistique explicite.
Les originaux du generateur restent en place ; les copies projet sont identiques.
Le statut technique de generation ne constitue pas une validation utilisateur.

Les controles locaux et captures de cette galerie sont conserves dans
`work/qa/tmnt-gallery/`. Ils ne modifient ni le jeu ni ses verrous.
