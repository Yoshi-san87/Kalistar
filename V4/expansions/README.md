# Lots d'ajout

Un lot date `YYYY-MM-DD-sujet` rassemble la fabrication d'un ajout :
sources, selection, profils de preparation, scripts et preuves.
Certains fichiers servent encore aux creations courantes. Ne rien deplacer
ou supprimer sans analyser les references.

Le `set.json` d'un ancien lot est un constat date, pas le catalogue courant.
Les sorties publiees sont identifiees par les registres et profils actifs.
Nouveaux essais repetes dans `work/`, preuves finales selectionnees dans le lot.
