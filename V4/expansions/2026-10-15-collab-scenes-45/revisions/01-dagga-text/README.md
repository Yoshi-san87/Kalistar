# Correction de composition avant publication

Le premier rendu de Dagga a ete refuse par le controle `Recit hors cadre apres
equilibrage` : sa description passait sur cinq lignes. Aucun PSD de Dagga
n'avait ete sauvegarde. Les onze cartes precedentes sont intactes.

Le texte est raccourci de 206 a 180 caracteres sans changement d'illustration,
de statistiques, de typographie ni de geometrie. Les fichiers precedents sont
conserves bit pour bit sous `previous/`, ainsi que le journal de l'echec.
`before.json` reste strictement inchangé. Le manifeste de cette correction
ajoute les nouvelles empreintes et les relie aux anciennes ; il ne remplace
aucun verrou natif valide. Les controles natifs complets restent obligatoires.
