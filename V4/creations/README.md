# Creations publiees

Un dossier par `model-id`, avec profil, PNG, PSD et sources selon son pipeline.
Le registre `../donnees/catalogue.json` determine la publication ; la presence
d'un dossier ne suffit pas.

Lire le profil courant et sa `nativeRevision`. Une revision ne change pas
l'identite du modele/personnage pour contourner la compatibilite des saves.
Conserver les anciens originaux dans le lot de revision, sans ecraser les
references approuvees.
