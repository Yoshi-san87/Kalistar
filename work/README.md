# Travaux locaux

Seul ce README est suivi. Les autres fichiers ici sont exclus de Git.

| Destination | Usage |
| --- | --- |
| `qa/<sujet>/` | Captures, traces et mesures intermediaires |
| `scratch/<sujet>/` | Essais de scripts ou de composition |
| `staging/<sujet>/` | Copies de preparation non officielles |

Un sujet = un dossier nomme clairement. Garder les saves personnelles a part.
Les sorties finales d'une carte vont dans `V4/creations/<model-id>/` et ses preuves
retenues dans le lot/la livraison, apres validation.

Rien ici ne fait reference pour le catalogue. Aucun script ne supprime ce dossier
automatiquement. Examiner et preserver tout fichier utile avant un nettoyage.
Voir [organisation](../docs/ORGANISATION.md).
